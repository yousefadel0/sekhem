# First-week checklist

Owner: Engineering Manager · Last verified: 2026-09-02

- Complete identity/MFA/NDA/IP/acceptable-use and least-privilege access.
- Clone and verify Node 22/pnpm 11.1.2 frozen installs.
- Run frontend and Backend locally without Production secrets.
- Bootstrap a disposable DB and run canonical verification.
- Read module truth matrix, RBAC, trust boundaries, R&D and deployment runbooks.
- Open one non-Production MR using the template and CODEOWNER flow.
- Demonstrate secret handling, incident reporting, and offboarding expectations.
- Do not receive Production DB/provider/host access unless separately approved.
