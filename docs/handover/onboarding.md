# Authorized engineer onboarding

Owner: Engineering Manager · Last verified: 2026-09-02

Use an individual identity with MFA, minimum GitLab role, signed commits where supported, NDA/IP assignment and acceptable-use acknowledgement. Provide private repository/VPN access and non-Production configuration only. Walk through system status, trust boundaries, quickstart, DB gate, MR template, CI, deployment separation, incident response, and prohibited external AI/code uploads. Production access is not granted by default.
